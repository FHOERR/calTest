# CAL-002：前端界面与样式实现

## 概述

完成了基于 CAL-001 规范的计算器前端界面实现，包含完整的 HTML 结构、现代化 CSS 样式和交互逻辑。

## 文件清单

### 1. `index.html` - 页面结构
- **显示区域**：
  - 主显示：展示当前输入或计算结果（字号 48px）
  - 辅助显示：展示前一操作数、运算符与轻量提示（字号 14px）
  
- **按钮网格**：
  - 4 列规则网格布局
  - 行 1：AC、DEL、÷、×
  - 行 2：7、8、9、−
  - 行 3：4、5、6、+
  - 行 4：1、2、3、=
  - 行 5：0（双列）、.、=

### 2. `styles.css` - 样式与布局

#### 设计要点
- **卡片式居中布局**：白色背景、圆角、阴影
- **现代配色**：
  - 数字按钮：浅灰背景（#f5f7fa）
  - 运算符：紫色渐变（#667eea → #764ba2）
  - 等号：红色渐变（#f093fb → #f5576c）
  - 功能键（AC/DEL）：红色（#ff6b6b）

- **交互反馈**：
  - 悬停：向上移动 2px + 阴影增强
  - 按下：缩放 96% + 阴影减弱
  - 焦点：蓝色焦点环（3px offset）
  - 过渡时间：120ms（cubic-bezier 曲线）

#### 响应式断点
- **桌面端**（>480px）：最大宽度 420px，按钮 56px 高
- **平板**（360-480px）：适应屏幕，按钮 48px 高
- **手机**（<360px）：紧凑布局，按钮 44px 高，按钮间距 8px

#### 特色功能
- 0 键占双列，增强触达感
- 深色模式支持（@media prefers-color-scheme: dark）
- 打印样式支持
- 键盘焦点可见性（focus-visible）

### 3. `script.js` - 交互逻辑

#### 核心方法
- **appendNumber(number)**：追加数字或小数点
  - 每个操作数最多一个小数点
  - 首位输入小数点显示为"0."
  - 显示限制 12 位有效字符
  
- **chooseOperation(operation)**：选择运算符
  - 若前面已有运算，先执行前面的运算
  - 支持连续计算（直接按下一个运算符）
  - 防止开头输入运算符

- **compute(silent)**：执行计算
  - 除以 0 时进入错误态
  - 浮点误差修正（精度到 1e-10）
  - 超长结果采用科学计数法

- **delete()**：删除最后一位
  - 错误态下按 DEL 会清空所有

- **clear()**：清空所有状态
  - 重置操作数、运算符、错误态

- **setError()**：进入错误态
  - 显示"Error"，仅允许 AC 清空

#### 键盘映射
- 数字：0-9
- 小数点：.
- 运算符：+、-、*、/
- 等号：Enter、=
- 清空：Escape、C、c
- 删除：Backspace

#### 错误处理
- 除以 0：显示"Error"，锁定状态，仅允许 AC 恢复
- 非法输入：自动忽略，保持当前状态
- 无效序列：不执行操作

#### 状态管理
- `currentOperand`：当前操作数
- `previousOperand`：前一操作数
- `operation`：当前运算符
- `isInError`：错误标志
- `lastWasEquals`：是否刚得出结果（用于连续计算判断）

## 实现规范对标

| 规范要求 | 实现方式 |
|---------|--------|
| 简洁、现代、柔和阴影、高对比可读性 | 渐变色、圆角、精细阴影、无衬线字体 |
| 卡片式居中布局 | flex 容器 + 最大宽度 420px |
| 4 列规则网格 | CSS Grid grid-template-columns: repeat(4, 1fr) |
| 响应式 320px 起可用 | 三级响应式断点 |
| 100-150ms 轻微缩放/亮度变化 | transition: all 0.12s cubic-bezier(0.4, 0, 0.2, 1) |
| 键盘焦点可见 | :focus-visible 焦点环 |
| 连续计算 | 运算符选择时自动执行前一运算 |
| 按钮替换行为 | 连续运算符不追加操作数 |
| 除以 0 处理 | 显示"Error"，锁定状态 |
